# Clínica Spa Viessence

Landing page estática da Clínica Spa Viessence (HTML, CSS e JavaScript puros, sem build).

## Arquivos

- `index.html`: a página inteira (estilos, scripts e imagens embutidos)
- `momentos.mp4` e `momentos-poster.jpg`: vídeo da seção "Momentos de calma" e imagem de capa
- `.nojekyll`: faz o GitHub Pages servir os arquivos como estão

## Publicar no GitHub Pages

1. Envie todos os arquivos para a raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Para editar depois

- O número do WhatsApp: nos links `https://wa.me/?text=...` do `index.html`, coloque o número com DDI e DDD antes do `?`, por exemplo `https://wa.me/5511999999999?text=...`.
- Os links de Instagram, TikTok e Facebook estão apontando para as páginas iniciais das redes. Troque pelos perfis da clínica.
